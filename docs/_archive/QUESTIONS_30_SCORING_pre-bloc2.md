## Architecture du test

| Phase | Questions | Type | Objectif |
|-------|-----------|------|----------|
| 1 | 1 à 20 | Typage | Déterminer le profil dominant et secondaire |
| 2 | 21 à 26 | Intensité | Mesurer la profondeur du schéma |
| 3 | 27 à 30 | Contexte | Adapter le résultat au statut du lecteur |

# PHASE 1 : QUESTIONS DE TYPAGE (1 à 20)

## Conventions phase 1

- 4 options par question (A, B, C, D)
- Chaque option correspond à un profil unique
- Chaque option choisie ajoute 3 points au profil correspondant
- 5 questions par profil ciblées en position A pour équilibre

## Légende des profils

- **M** = Mendiant de Luxe (Performance)
- **S** = Sauveur Épuisé (Utilité)
- **C** = Contrôleur Anxieux (Contrôle)
- **F** = Fantôme Relationnel (Fuite)

## Vérification distribution phase 1

| Profil | Position A | Position B | Position C | Position D | Total |
|--------|------------|------------|------------|------------|-------|
| Mendiant (M) | 5 | 4 | 4 | 7 | 20 |
| Sauveur (S) | 5 | 6 | 5 | 4 | 20 |
| Contrôleur (C) | 5 | 5 | 7 | 3 | 20 |
| Fantôme (F) | 5 | 5 | 4 | 6 | 20 |

Score maximum théorique par profil : 60 points (20 occurrences × 3 points).

**Contrainte critique** : pour chaque question, les 4 options doivent couvrir les 4 profils sans doublon. Le test de validation 4.3 doit vérifier cette contrainte automatiquement.

# PHASE 3 : QUESTIONS DE CONTEXTE (27 à 30)

## Conventions phase 3

- 4 questions à choix unique avec valeur sémantique
- Pas de scoring, sert à adapter le résultat
- Chaque question cible un champ spécifique du contexte

---

## Question 27

**Énoncé :** Avez-vous déjà lu le livre "Vous avez tout compris. Rien n'a changé." ?

**Champ cible** : `statutLivre`

- Oui, je l'ai lu en entier → `lu_complet`
- Oui, je suis en train de le lire → `lu_partiel`
- Non, pas encore → `pas_lu`

(Note : 3 options ici, pas 4. La question est strictement informative.)

---

## Question 28

**Énoncé :** Quelle est votre situation relationnelle actuelle ?

**Champ cible** : `situation`

- En couple stable et globalement satisfaisant → `couple_stable`
- En couple compliqué ou conflictuel → `couple_difficile`
- Célibataire après une rupture récente → `rupture_recente`
- Célibataire depuis longtemps → `celibat_long`

---

## Question 29

**Énoncé :** Comment décririez-vous votre état émotionnel ce mois-ci ?

**Champ cible** : `etatEmotionnel`

- Globalement fonctionnel et stable → `fonctionnel`
- Tendu, fatigué, sur les nerfs → `tendu`
- En crise, en grande souffrance → `crise`
- En reconstruction après une crise récente → `reconstruction`

---

## Question 30

**Énoncé :** Êtes-vous prêt à investir dans un accompagnement transformateur ?

**Champ cible** : `pretAAgir`

- Oui, je suis prêt à m'engager maintenant → `maintenant`
- Oui, mais pas tout de suite, dans quelques semaines ou mois → `bientot`
- Je veux d'abord comprendre, lire, m'informer → `comprendre_dabord`
- Je ne sais pas encore → `incertain`

# ALGORITHME DE SCORING COMPLET

## Pseudo-code de la fonction principale

```typescript
function calculerResultat(reponses: Reponses, questions: Question[]): Resultat {
  // Phase 1 : calcul du profil dominant et secondaire
  const scoreProfils = calculerScoreProfils(reponses.typage, questions);
  const { profilDominant, profilSecondaire } = determinerProfils(scoreProfils, reponses.typage, questions);
  
  // Phase 2 : calcul de l'intensité
  const scoreIntensite = Object.values(reponses.intensite).reduce((sum, v) => sum + v, 0);
  const intensite = determinerIntensite(scoreIntensite);
  
  // Phase 3 : composition avec contexte
  return {
    profilDominant,
    profilSecondaire,
    scoreProfils,
    intensite,
    scoreIntensite,
    statutLivre: reponses.contexte.statutLivre,
    situation: reponses.contexte.situation,
    etatEmotionnel: reponses.contexte.etatEmotionnel,
    pretAAgir: reponses.contexte.pretAAgir,
  };
}

function calculerScoreProfils(typage: Record<number, string>, questions: Question[]): ScoreProfils {
  const score: ScoreProfils = { mendiant: 0, sauveur: 0, controleur: 0, fantome: 0 };
  
  const questionsTypage = questions.filter(q => q.type === 'typage') as QuestionTypage[];
  
  for (const question of questionsTypage) {
    const optionId = typage[question.id];
    if (!optionId) throw new Error(`Réponse manquante pour Q${question.id}`);
    
    const option = question.options.find(o => o.id === optionId);
    if (!option) throw new Error(`Option ${optionId} introuvable pour Q${question.id}`);
    
    score[option.profil] += 3;
  }
  
  return score;
}

function determinerProfils(
  score: ScoreProfils, 
  typage: Record<number, string>, 
  questions: Question[]
): { profilDominant: ProfilId; profilSecondaire: ProfilId | null } {
  const profilsTries = (Object.keys(score) as ProfilId[])
    .sort((a, b) => score[b] - score[a]);
  
  // Cas 1 : pas d'égalité au sommet
  if (score[profilsTries[0]] > score[profilsTries[1]]) {
    const dominant = profilsTries[0];
    const second = profilsTries[1];
    const profilSecondaire = (score[dominant] - score[second]) < 4 ? second : null;
    return { profilDominant: dominant, profilSecondaire };
  }
  
  // Cas 2 : égalité parfaite, application du tie-breaker
  return appliquerTieBreaker(score, typage, questions);
}

function appliquerTieBreaker(
  score: ScoreProfils, 
  typage: Record<number, string>, 
  questions: Question[]
): { profilDominant: ProfilId; profilSecondaire: ProfilId | null } {
  const maxScore = Math.max(...Object.values(score));
  const profilsExAequo = (Object.keys(score) as ProfilId[])
    .filter(p => score[p] === maxScore);
  
  // Critère 1 : score discriminant sur questions 1, 4, 11, 19
  const questionsDiscriminantes = [1, 4, 11, 19];
  const scoresDiscriminants: ScoreProfils = { mendiant: 0, sauveur: 0, controleur: 0, fantome: 0 };
  
  for (const qId of questionsDiscriminantes) {
    const optionId = typage[qId];
    const question = questions.find(q => q.id === qId) as QuestionTypage | undefined;
    const option = question?.options.find(o => o.id === optionId);
    if (option) scoresDiscriminants[option.profil] += 1;
  }
  
  const sortedByDiscriminant = profilsExAequo
    .sort((a, b) => scoresDiscriminants[b] - scoresDiscriminants[a]);
  
  if (scoresDiscriminants[sortedByDiscriminant[0]] > scoresDiscriminants[sortedByDiscriminant[1]]) {
    return { profilDominant: sortedByDiscriminant[0], profilSecondaire: null };
  }
  
  // Critère 2 : ordre prédéfini Fantôme > Contrôleur > Sauveur > Mendiant
  const ordrePrioritaire: ProfilId[] = ['fantome', 'controleur', 'sauveur', 'mendiant'];
  for (const profil of ordrePrioritaire) {
    if (profilsExAequo.includes(profil)) {
      return { profilDominant: profil, profilSecondaire: null };
    }
  }
  
  throw new Error('Tie-breaker impossible');
}

function determinerIntensite(score: number): IntensiteId {
  if (score < 6 || score > 30) {
    throw new Error(`Score d'intensité hors plage : ${score}`);
  }
  if (score <= 13) return 'surface';
  if (score <= 22) return 'modere';
  return 'profond';
}
```
